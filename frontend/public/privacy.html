1. Siapa kami

_self.manage ("aplikasi") adalah aplikasi web pencatat keuangan pribadi yang dikembangkan dan dioperasikan secara perorangan. Aplikasi didistribusikan sebagai halaman statis dan dijalankan di peramban (browser) pengguna.

2. Data yang diakses

Data Tujuan Disimpan di server kami?
Isi Google Spreadsheet yang Anda pilih (transaksi, akun, anggaran, tagihan, target) Membaca dan menulis catatan keuangan Anda saat Anda menambah, mengubah, atau menghapus data Tidak. Data hanya berpindah antara browser Anda dan Google.
Access token Google (OAuth) Mengotorisasi permintaan ke Google Sheets API atas nama Anda Tidak. Token hanya berada di sessionStorage browser dan hilang saat tab ditutup.
ID spreadsheet & nama panggilan (opsional) Mengingat spreadsheet mana yang Anda pakai saat membuka aplikasi kembali Tidak. Hanya di localStorage browser Anda.

Aplikasi tidak meminta, menyimpan, atau menampilkan alamat email Anda. Tidak ada pendaftaran akun, tidak ada kata sandi, tidak ada profil pengguna di sisi kami.

3. Izin (scope) Google yang diminta

  • https://www.googleapis.com/auth/spreadsheets — membaca dan menulis isi spreadsheet yang Anda pilih, agar fitur tambah/ubah/hapus transaksi dapat bekerja.
  • https://www.googleapis.com/auth/drive.file — membuat berkas spreadsheet baru di Google Drive Anda bila Anda memilih opsi "buat baru otomatis". Aplikasi tidak dapat melihat berkas Drive lain.

Aplikasi tidak meminta izin untuk email, kontak, kalender, atau seluruh isi Drive Anda.

4. Kepatuhan Limited Use Google

Penggunaan dan pengiriman informasi yang diterima dari Google API oleh _self.manage mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use. Secara khusus: data Google Anda hanya digunakan untuk menyediakan fitur yang Anda minta di aplikasi, tidak dipakai untuk iklan, tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dibaca oleh manusia mana pun.

5. Tidak ada pelacakan

Aplikasi tidak memasang cookie iklan, pixel, analitik pihak ketiga, maupun profil perilaku. Permintaan jaringan hanya menuju domain Google (autentikasi dan Sheets API) serta penyedia hosting statis.

6. Penyimpanan & keamanan

  • Semua komunikasi melalui HTTPS.
  • Access token bersifat sementara (±1 jam) dan tidak pernah dikirim ke server aplikasi.
  • Kepemilikan spreadsheet tetap sepenuhnya milik Anda, termasuk hak menghapusnya.

7. Mencabut akses & menghapus data

  • Cabut izin aplikasi kapan pun di myaccount.google.com/permissions.
  • Hapus data dengan menghapus spreadsheet Anda di Google Drive.
  • Hapus jejak lokal dengan tombol "Lepas koneksi" di menu Pengaturan aplikasi, atau bersihkan data situs di peramban Anda.
